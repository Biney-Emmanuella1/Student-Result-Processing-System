# Student Result Processing System
## Description
This is a program that processes a student's exam score and displays the corresponding grade. 
The program validates user input to ensure it does not crash and only accepts valid scores between 0 and 100.

## Features
- Reads a student's score from user input
- Rejects scores outside the range of 0-100
- Handles invalid input like letters or symbols
- Displays the corresponding grade based on the score
- Uses error handling to ensure the program never crashes

## Grading Scale
| Score Range | Grade |
| --- | --- |
| 90 - 100 | A |
| 80 - 89 | B |
| 70 - 79 | C |
| 60 - 69 | D |
| 50 - 59 | E |
| 0 - 49 | F |
